# W8: Search by your words
Owner: Mirdul (server) + Anand (UI)
Branch: mirdul (server), anand (UI)
User sees: Features page, "Your words" next to "Name" on the search box: type a few words, press Enter, and see "Features that fired most on your words": the query's tokens as the model split them, then each feature with a bar for its share of its own peak (relative_to_max) and the token it fired on most. Searching by name stays as it was.
Endpoint / data used: `POST /api/v1/features/search` with `max_density: 0.01` always sent and no toggle (server/README.md: without it, very common features fill every result); `top_n` 10, `sort` activation.
Real demo example (feature ids, prompt, strength): Mirdul's real-mode check (server/README.md, server/scripts/w8_check.py): with max_density 0.01, "music", "court ruling" and "recipe for pasta" all found sensible features.
Honest limit shown on screen: "Shows which features fired on your words, not what the words mean. Features that fire on more than 1% of all tokens are left out. Ranked by raw activation."
Status: working (server and UI)
