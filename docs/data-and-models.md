# Data and models

What NeuronLens uses, where it comes from, and what is and is not in the repository. Licenses were not confirmed from the sources while this page was written (the upstream pages could not be reached), so each row says where to check rather than quoting terms. Read the upstream license before you redistribute anything built from these.

## What is used

| Name | Used for | Where it comes from | Terms |
| --- | --- | --- | --- |
| GPT-2 small (`gpt2`) | The model whose layer-8 activations the SAE is trained on, and the model steered in the app | Hugging Face Hub, loaded by name with `transformers` | Check the upstream license (model card of `gpt2` on the Hub) |
| GPT-Neo-125M (`EleutherAI/gpt-neo-125M`) | The second, experimental model | Hugging Face Hub, loaded by name with `transformers` | Check the upstream license (model card of `EleutherAI/gpt-neo-125M`) |
| FineWeb-Edu, `sample-10BT` | Training text for the SAEs, and the text scanned to find each feature's strongest examples | Hugging Face dataset `HuggingFaceFW/fineweb-edu`, read from local parquet files | Check the upstream license (dataset card). The text is drawn from web pages, so its terms depend on the card and on the original sites |
| Gemini | Generates the feature names and the "ambiguous" marks, from each feature's strongest examples and next-word effects | Google's Gemini API, called by `ml/scripts/auto_label.py` with your own API key | Check the upstream license: Google's Gemini API terms apply to your use of the API, including to the generated labels |
| OpenAI's published GPT-2 SAE (`v5_32k`, layer 8) | Only the comparison in `ml/scripts/compare_published.py` | Downloaded from the Hub by that script | Check the upstream license |

## What is not in the repository

- **Databases.** The real databases (`data/neuronlens.db` for GPT-2, `data/neuronlens-neo.db` for GPT-Neo-125M) are not in git. They hold the feature names, example sentences taken from FineWeb-Edu, and the metrics. Only `contracts/fixtures/sample.db`, a synthetic database made by `contracts/fixtures/make_fixture.py` with every text field marked `[sample]`, is committed.
- **Checkpoints.** The trained SAE files (`*.pt`) are not in git.
- **Training text.** FineWeb-Edu is not in git.
- **Derived data files.** `data/cofire.json` and `data/map2d.json` are not in git.

Everything the app shows in real mode can be rebuilt from the code in `ml/`. Without a database and checkpoint the app runs in mock mode on the sample database.

## How to rebuild

The commands, in order, are in [ml/README.md](../ml/README.md) (GPT-2) and [features/multi-model.md](features/multi-model.md) (GPT-Neo-125M, with the exact lines for each step):

1. Put the FineWeb-Edu `sample-10BT` parquet files in a folder. The scripts read `*.parquet` from `--data-dir`, default `~/data/fineweb/sample/10BT`.
2. Train: `ml/scripts/run_training.py ml/configs/gpt2-small.yaml` (100 million activations, k = 32, 12,288 features). The Neo config is `ml/configs/gpt-neo-125m.yaml`; its run used 37.5 million tokens.
3. Evaluate: `ml/scripts/run_evals.py`.
4. Build the database: `ml/scripts/make_index.py`, which scans 3,000 sequences and writes the schema in `contracts/schema.sql`.
5. Name the features: `ml/scripts/auto_label.py` (needs `pip install -r ml/requirements-labelling.txt` and `GEMINI_API_KEY` in the environment or a git-ignored `.env`). Labels can differ between runs; the repository does not contain the labels used for the numbers in the README except for the 16 hand-written entries in `ml/labels.json`.
6. Optional data files: `ml/scripts/build_cofire.py` and `ml/scripts/build_map.py` ([phase4-data-files.md](phase4-data-files.md)).
7. Start the server in real mode: [demo-startup.md](demo-startup.md).

Training and indexing need a CUDA GPU. The development machine had an RTX 4070 Laptop GPU with 8 GB. Seeds are fixed (42 for training), but a retrained checkpoint may differ from the one behind the README numbers, because GPU kernels are not fully deterministic.

## Limits

- The numbers in the README were measured on one training run per model, not averaged.
- Labels are generated by a language model and were not checked by hand; this repository records no full review. Some are wrong or too broad.
- `ml/labels.json` belongs to GPT-2 features. Do not use it for another model.
