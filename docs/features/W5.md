# W5: Multi-concept steering
Owner: Mirdul (server) + Anand (UI); ML by Prabodh
Branch: mirdul (server), anand (UI), prabodh (ML)
User sees: Two or three features steered together on one prompt: the baseline and the combined text, a loop warning, and for each feature whether it appears more, less or about the same in the combined text.
Endpoint / data used: not decided (Mirdul proposes, Prabodh signs off). ML function: multi_steering_check in ml/neuronlens/steering_checks.py (docs/phase4-ml-api.md, section W5).
Real demo example (feature ids, prompt, strength): none yet. The manual runs so far (seed 42, 60 new tokens, two pairs, three prompts) showed no run with both activations higher; for example 3446 + 1863 on "The band walked on stage and" at 0.25 and 0.5: only 3446 reads higher (11.82 and 10.80), 1863 stays 0.00. Details in docs/phase4-ml-api.md, W5. A real example needs both features clearly "higher" on the same prompt with no loop warning.
Honest limit shown on screen: 2 to 3 features, amplify only. A combination can break the text at strengths where each feature alone is fine, so the single-feature runs should be shown beside it. The activation readings are taken on the finished text, re-encoded without steering; they say whether each feature appears in the text, not whether the output is better. The loop warning catches repetition, not all poor text. In the manual runs so far the features did not add up visibly: a feature that read high alone read 0.00 in the combination. This was a small search, not a proof that it cannot work.
Status: in progress: automated search for a real demo example is under way; the first manual runs showed none
