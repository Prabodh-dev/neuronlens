# W5: Multi-concept steering
Owner: Mirdul (server) + Anand (UI); ML by Prabodh
Branch: mirdul (server), anand (UI), prabodh (ML)
User sees: Two or three features steered together on one prompt: the baseline and the combined text, a loop warning, and for each feature whether it appears more, less or about the same in the combined text.
Endpoint / data used: not decided (Mirdul proposes, Prabodh signs off). ML function: multi_steering_check in ml/neuronlens/steering_checks.py (docs/phase4-ml-api.md, section W5).
Real demo example (feature ids, prompt, strength): none recorded yet; to be filled from a GPU run (ml/scripts/phase4_demo.py --combine).
Honest limit shown on screen: 2 to 3 features, amplify only. A combination can break the text at strengths where each feature alone is fine, so the single-feature runs should be shown beside it. The activation readings are taken on the finished text, re-encoded without steering; they say whether each feature appears in the text, not whether the output is better. The loop warning catches repetition, not all poor text.
Status: in progress
