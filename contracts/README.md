# Contracts

Only Prabodh edits `schema.sql` and `openapi.json`. Everyone else builds against them.
Contract changes are announced in the group chat first.

`fixtures/sample.db` is a small synthetic database (every text field marked `[sample]`)
generated by `fixtures/make_fixture.py`. It is not real data.

## Units

- `density` is a fraction, 0 to 1.
- `dead_pct` (in `metrics`) and `training_curve.dead_pct` are PERCENT, 0 to 100.
- `fvu` and `ce_recovered` are fractions.
- `density_hist` is over log10(density) and covers live features only.
- `tokens_json` keeps leading spaces exactly as tokenised.
