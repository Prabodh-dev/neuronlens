# X1: Steering check
Owner: Mirdul
Branch: mirdul
User sees: The baseline text and the steered text for one feature side by side, whether they differ, and the feature's activation on each text (higher, lower or about the same).
Endpoint / data used: /api/v1/steer/check
Real demo example (feature ids, prompt, strength): feature 3446, prompt "The band walked on stage and", amplify 0.5, seed 42; activation 0.00 to 12.44 (higher).
Honest limit shown on screen: The check reads the feature on the finished text, re-encoded without steering. It says whether the feature appears in the output, not whether the output is better. A feature already near its maximum cannot show an increase (feature 1863: 18.57, max about 19.7). For ablate, if the concept's word is still in the text the feature still fires (feature 1863 read "about the same"). Results depend on the prompt and the strength (feature 3446 read 0.00 at 1.0, where the text drifted to "video"; feature 1863 went from 0.00 to 17.27 at 0.5 and read 0.00 at 1.0).
