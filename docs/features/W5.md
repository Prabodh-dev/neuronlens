# W5: Multi-concept steering
Owner: Mirdul (server) + Anand (UI); ML by Prabodh
Branch: mirdul (server), anand (UI), prabodh (ML)
User sees: Two or three features steered together on one prompt: the baseline and the combined text, a loop warning, and for each feature whether it appears more, less or about the same in the combined text.
Endpoint / data used: `POST /api/v1/steer/multi` (Mirdul), on multi_steering_check in ml/neuronlens/steering_checks.py (docs/phase4-ml-api.md, section W5).
Real demo example (feature ids, prompt, strength): features 4280 ("that – support that claim") + 9530 ("sin – moral wrongdoing"), prompt "The man walked into the room and", amplify 0.5 on both, seed 42. 4280 went 0.00 -> 4.20 and 9530 went 0.00 -> 5.89 (both "higher"); steered alone at 0.5 they read 2.29 and 4.45. Steered text: " saw the man that had been talking, and had accused the man of making a false statement, claiming he was a Christian. A ..." (shortened). Found by an automated search (600 candidates, 100 pairs) and checked on held-out prompts: both rose together on 2 of 3. Details in docs/phase4-ml-api.md, W5.
Honest limit shown on screen: The example was found by a search, so there is a selection effect (the pair was picked from 100; two other searched pairs did not hold on held-out prompts). It depends on the prompt: on "The woman looked at him and" only one of the two features moved. The strength window is narrow: recorded at 0.5, and readings were lost at higher strengths in earlier runs. 2 to 3 features, amplify only, and the single-feature runs are shown beside the combination. The readings show which concepts were active in the finished text, re-encoded without steering. Steering is a test, not a fix; the combined text is not shown as better. The loop warning catches repetition, not all poor text.
Status: working (ML, server `POST /steer/multi`, UI): a Combine tab on the Steer page, single-feature runs shown as activation numbers only
